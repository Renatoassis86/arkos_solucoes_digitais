## 5. Amostra de Copywriting & Narrativa (Parágrafos Reais)
> "This page is decorated with the Fullstory Skills framework. Every meaningful interactive element has been enriched with semantic attributes so agents can navigate the accessibility tree directly instead of guessing from layout or coordinates."

> "Every interactive element has a data-fs-element attribute with a human-readable name (for example: "Get Demo CTA", "Search Input", "Submit Contact Form", "Blog Post Card: Article Title"). The same name is mirrored into aria-label. Use these names to identify and reference elements rather than relying on visual position."

> "Buttons render as <button> with role="button". Selectable options (radio / tab / accordion) carry role and aria-checked / aria-selected / aria-expanded. aria-disabled="true" means the element is present but cannot be interacted with right now."

> "The page uses landmark roles: role="banner" for the header, role="navigation" for nav and breadcrumbs, role="main" for the primary content, role="contentinfo" for the footer. The data-section attribute groups elements into logical regions ("hero", "footer", "main-content", a section name)."

> "Cards and content blocks carry structured business data via individual data-* attributes. The data-fs-properties-schema attribute on the same element is a JSON schema describing the available properties and their types: str (string), real (decimal number), int (integer), bool (boolean), date (ISO date)."

> "Items in repeated lists (cards, search results, plan tiers) carry a data-position attribute with a 1-based index. Use it to reference "the third plan card" or "the second result"."

> "Elements with data-role-hint="primary-action" are the page's primary calls to action (sign up, request demo, submit form). Other hints: submit, cancel, close, open-modal, navigate."

> "Capture real user behavior and put it to work, so your AI moves faster, and your experience improves."
